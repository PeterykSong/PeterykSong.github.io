## 1-2. pretrained G1 locomotion policy 실행

```bash
./isaaclab.sh play --rl_library rsl_rl --task Isaac-Velocity-Flat-G1 --checkpoint pretrained --viz kit --num_envs 1
```
저 명령어 한줄은 이렇게 해석하면 된다. 
 - `play` : 학습이 아니라 이미 학습된 policy 실행
 - `rl_library rsl_rl` :     RSL-RL backend 사용
 - `task Isaac-Velocity-Flat-G1`: Unitree G1 flat-ground velocity tracking task. 즉 실행 task이름이다. 
 - `checkpoint pretrained` : Isaac Lab에서 제공하는 pretrained checkpoint 사용
 - `viz kit` : IsaacSim을 띄워서 화면으로 보여준다. 
 - `num_envs 1`  : 한대만 띄운다고 하는것이다.

## 1-3 G1에 command를 만들어보자. 

이 task는 velocity tracking task다. G1이 받는 주 명령은 다음과 같다. 
 - vx : 전진/후진 속도 [m/s]
 - vy : 좌우 이동 속도 [m/s]
 - wz : yaw 회전 속도 [rad/s]

이제 이걸 키보드로 입력받는걸 한번 해보자. 

먼저 teleop script를 하나 만들어보자.   
아마 tutorials 까지는 폴더가 있을것이다. g1 폴더만 하나 더 만들어보자. 
그리고 좀전까지 실행했던 play.py를 복사해서 이름을 바꿔 넣어보자. 

```bash
cd ~/IsaacLab

mkdir -p scripts/tutorials/g1

cp source/isaaclab_rl/isaaclab_rl/entrypoints/backends/play_rsl_rl.py \
scripts/tutorials/g1/g1_teleop.py
```

그런다음, g1_teleop.py를 편집해보자. 

상단에 아래 코드를 넣는다. 키보드 입력을 받는 모듈이다. 

```python
from isaaclab.devices import Se2Keyboard, Se2KeyboardCfg
```
Se2Keyboard는 Isaac Sim GUI에서 키보드 입력을 받아 SE(2) velocity command를 만들어준다.


그다음 192줄 근처즈음 가면 아레 코드내용이 있다. 편집을 했으니 코드가 좀 밀려있을것이다. 잘 감안할것. 

```python
policy = runner.get_inference_policy(device=env.unwrapped.device)
``` 
여기 바로 밑에 다음 코드를 붙여 넣자. 
```python
keyboard = Se2Keyboard(
    Se2KeyboardCfg(
        v_x_sensitivity=0.5,
        v_y_sensitivity=0.5,
        omega_z_sensitivity=1.0,
    )
)

keyboard.reset()
```
세번째 omega_z가 회전속도인데, 이거 늘여도 로봇이 팽팽 돌진 않을 것이다. policy가 회전에 좀 둔감하다. 

그다음 simulation loop를 수정한다. 주욱 내려가다보면 다음 내용이 있을 것이다. 
거의 230줄 가까이 가야 보일것이다. (원래는 222줄이었다)

```python
try:
      while True:
          start_time = time.time()
          with torch.inference_mode():
            actions = policy(obs)
            obs, _, dones, _ = env.step(actions)
```
그걸 아래와 같이 수정하자. 

```python
try:
  while True:
    start_time = time.time()
    with torch.inference_mode():
        # keyboard -> [vx, vy, wz]
        cmd = keyboard.advance()

        # G1 velocity command 직접 덮어쓰기
        base_cmd = env.unwrapped.command_manager.get_command("base_velocity")
        base_cmd[:, 0] = cmd[0]
        base_cmd[:, 1] = cmd[1]
        base_cmd[:, 2] = cmd[2]

        # locomotion policy
        actions = policy(obs)

        # simulation
        obs, _, dones, _ = env.step(actions)
```

이제 이걸 실행해보면 화면이 뜬다. GUI화면에서 키보드커멘드를 눌러보면 머리위의 화살표가 바뀌면서 움직이는게 보일것이다. 

```bash

    --num_envs 1
```

키보드 커맨드는 다음과 같다.

# 2. ROS에 odometry 퍼블리시
여기서 일이 좀 꼬인다. 

ROS 와 IsaacLab을 연결하는데는 몇가지 방법이 있다. 

1) Isaac Lab을 실행하는 스크립트에서 ROS topic을 정의해서 쓰는 방법. 
  : 이 경우는 ROS의 파이썬 버전과 Isaac Lab의 파이썬 버전이 맞아야 한다. (여기서 나가리되었다.)

2) Isaac sim의 ros bridge 기능을 사용하는 방법
   : Bridge extension 활성화한 다음 쓰면 되는데, launch script에서 활성화시킨다. 이 경우 파이썬 버전 충돌을 피할 수 있다. 

3) Isaac Sim에서 실행환경을 구성하는 경우
   : 이 경우 Action graph를 이용하여 ROS Topic을 정의할 수 있다. 

여기선, 향후 연구 확장성을 위해 3번으로 방향을 틀어야 할 것 같다.

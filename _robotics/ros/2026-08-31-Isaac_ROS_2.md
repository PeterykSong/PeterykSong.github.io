# 들어가면서

Isaac SIM의 업데이트 속도가 뭐 이리 빠른지 모르겠다. 

작년에 내가 배울땐 4.5였는데, 1년반만에 무려 6.0이라니.... 히스토리들은 좀 찬찬히 적어보고.. 일단 ROS 와 연동하기 위한 설치를 알아본다. 


# Isaac Lab 설치기. 

설치된 Isaac sim을 확인해보자. 

```bash
echo $ISAACSIM_PATH
```

아무것도 안뜬다면, 경로를 찾아 넣어보자. 

```bash
echo 'export ISAACSIM_PATH=$HOME/isaacsim' >> ~/.bashrc
```
그 옛날, 도스 명령어는 그렇게 잘 외워댔는데, 이제 명령어 외우는게 쉽지가 않다. 더듬더듬......


파이썬 버전도 확인해보자. 

```bash
lairpeteryksong@Lair5080Peter:~/isaacsim$ ./python.sh --version
```

3.12 이상이 되어줘야 한다. 저 python.sh를 매번 찾아가서 실행하기 귀찮으니까, 

```bash
echo 'export ISAACSIM_PYTHON_EXE=$HOME/isaacsim/python.sh' >> ~/.bashrc
```
로 bash에 넣어두면 편하다. 

## Isaac Lab 설치에 필요한 패키지 설치

```bash
sudo apt update
sudo apt install -y cmake build-essential git
``` 
일단 업데이트를 좀 해본다. 

## git 다운로드

```bash
cd ~
git clone https://github.com/isaac-sim/IsaacLab.git --branch develop
```

git을 받아오는 것으로 시작한다. 
git을 다 다운로드 받으면, 브랜치를 한번 확인해보자. 드

```bash
cd ~/IsaacLab
git branch --show-current
```

아마, 별 무리 없이 develop일 것이다. 

## Isaac Sim과 Isaac Lab을 연결

```bash
cd ~/IsaacLab
ls -ld _isaac_sim
``` 
이렇게 해보면,_isaac_sim이 없다고 한다. 

```bash
ln -s $ISAACSIM_PATH _isaac_sim
ls -l _isaac_sim
```
다른 파일도 연결되었는지 확인해보자.

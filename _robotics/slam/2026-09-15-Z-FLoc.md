참고 논문을 찾아보니 매우 인상적이어서 읽어본 논문이다. 
이 논문이 인상적인건, 학습을 최대한 자제한 상태에서, Zero-Shot에 포커스를 두었다는 부분과,   
가장 최근 논문답게 관련연구들이 잘 정리되어있다. 그 부분이 인상적이다. 

# Intro
초록을 읽어보면 핵심 문구가 눈에 들어온다.   
geometric primitives...... we extract these primitives from bird's eye view(BEV) projection of monocular 3D reconstrucions .... match them to floorplan via dedicated minimal solvers........

즉, RGB 이미지를 이용해 3차원 공간을 재구성하고(monocular 3D reconstructions), 그걸 2차원으로 압축하고(BEV), 여기서 직선과 원을 뽑아낸 뒤, 별도의 solver를 이용해 2D CAD도면(floorplan)과 매칭을 수행하여 Global localization을 수행한다는 것이다.  

그 외에 이런 저런 말들이 많이 작성은 되어있는데 논문의 서문 특성상 개념적인 말들이 있는 것이니 크게 눈이 가지는 않는다. 

어쨌든 이 연구를 통해 Zero-shot 상태에서 데이터셋을 학습하지 않고서도 localization을 가능케 한다고 하는데, LaLaLoc 과 같은 Indoor-2D CAD VPR 분야의 트렌드와 미묘하게 다른 부분이 있다.

# Zero-Shot Floorplan Localization

## 문제 정의
연속된 RGB이미지가 주어진다. 이 이미지들의 카메라 포즈(SE(3)) 와 카메라 내부값(intrinsic)도 같이 주어진다. 이걸 토대로 SE(2)인 2D 캐드도면상의 Pose를 찾는 것이다.

전체 pipeline 이미지에서 이런 과정을 간략히 보여주고 있다.   

Input 데이터에 대해, 3차원 공간 재구성을 하는 라인과, 이 이미지에서 객체 인식을 통해 벽과 바닥을 구분해내고, 이걸 재구성된 3차원 공간에 적용시켜 벽 정보만 추출, 이걸 Top-view 로 변환한다. 여기서 나온 선과 원을 추출하여 FloorPlan의 원과 선들과 매칭시키는 작업을 수행하는데, 이때 Model estimation이 논문에서 말하는 Solver다. 그리고 그 문제를 풀기위한 Objective function이 Model scoring이라는 이름으로 정리되어있다. 이를 통해 위치를 추정하고 location과 trajectory를 추정해낸다. 

천천히 톺아보자. 



## 사용된 Foundation 모델

이 논문에선 두가지 모델을 사용한 것이 눈에 띈다. 그걸 시작으로 전체 파이프라인을 순서대로 번호를 매겨보자. 

1) RGB 이미지와 카메라 포즈정보가 입력된다. 
2-1) 이미지 정보를 토대로 3차원으로 재구성한다. (MapAnything)
2-2) 원본 이미지 정보에서 벽과 바닥정보를 구분해 픽셀에 라벨링한다.(Mask2Former)
3) 3D PCD 맵에서 벽만 추출한 다음 BEV로 변환한다. 
4) FloorPlan과 BEV View에서 primitives(선, 원) 성분을 추출해낸다. 
5) 추출된 Primitives를 4개의 Solver를 이용해 비교하면서 RANSAC 알고리즘을 이용해 반복한다(iteration)
6) iteration을 통해 좀더 지지를 많이 받는 pose를 최종 가설로 선택한다. 

우선 사용한 모델에 대해 먼저 실습해본다. 

## 1. 입력정보
앞서 서술했듯이 RGB 이미지 시퀸스를 사용하는데, 거기에 더해 각 프레임의 상대 카메라 Pose정보 (SE(3)), 카메라 intrinsic 정보가 모두 주어진다.   
상대 Pose만 가지고 있기때문에, 나중에 중력추정을 해서 보정하는 작업을 거쳐야 한다.

그리고 이 정보와 Sync를 맞추기 위해 2D 건축 캐드도면(floorplan)이 필요하다.

## 2-1. 이미지정보를 토대로 3차원 재구성하기

이 논문에서는 들어오는 이미지 정보를 MapAnything을 통해 3차원으로 재구성한다. 사실 RGB-D를 사용한다거나, 다른 Vision SLAM의 기법들을 사용한다면 다른 대안도 있을텐데 굳이 foundation model 계열의 3차원 재구성방식을 사용한다. 장단점에 대해 고민해볼 여지가 있다.  

MapAnything은 한 장 이상의 RGB 이미지와 선택적인 calibration·depth·camera pose를 받아 metric 3D geometry와 camera를 한 번의 feed-forward 추론으로 예측한다. image-only 입력에서도 다음 요소를 함께 추정한다.

- 픽셀별 depth와 camera ray
- view별 camera pose
- 장면의 metric scale
- camera/world frame의 dense point map  

그 말인즉슨, Pose정보를 주지 않아도 돌아가긴 한단 소리. 물론 정확도/정밀도의 문제는 발생하겠지만.  

여기서 MapAnything의 상세한 디테일을 들여다보지는 않겠다. 그건 별도의 칸을 들여 리뷰해볼 사항이다. 여기선 활용방식에 대해 좀 더 파보자.  

### 핵심 입·출력 

MapAnything API는 `list[view dict]`를 입력받아 같은 순서의 `list[prediction dict]`를 반환한다. 이때 batch 차원 `B`와 view 개수 `N`은 다르다. 

#### 입력

| 키 | 전처리 후 shape | 의미 |
|---|---|---|
| `img` | `(B, 3, H, W)` | DINOv2 방식으로 정규화된 RGB |
| `data_norm_type` | 보통 `["dinov2"]` | encoder 정규화 정보 |

지금은 image-only로 진행했다. `load_images(...)`가 resize/crop, 정규화, batch 차원 생성을 담당한다. 선택적으로 `intrinsics (3,3)`, `depth_z (H,W)`, OpenCV `cam2world (4,4)` pose를 넣을 수 있지만 Albertville의 `poses.txt`와 `depth40.txt`는 이 형식이 아니다. Pose.txt 는 2D 좌표값과 Yaw 값이 으로 나와있어 3차원정보로 변환의 필요성이 있고, depth40.txt는 일종의 GT자료로 활용하는 데이터다. 간편하게 재현해보기 위해 여기선 이미지만 사용하여 수행한다. 

#### 주요 출력

| 키 | shape | 의미 |
|---|---|---|
| `pts3d` | `(B,H,W,3)` | 공통 world frame의 픽셀별 3D point |
| `pts3d_cam` | `(B,H,W,3)` | 해당 camera frame의 3D point |
| `depth_z` | `(B,H,W,1)` | camera optical axis 기준 Z-depth |
| `camera_poses` | `(B,4,4)` | OpenCV 축의 cam2world pose |

### Gravity 확인

1) 우선 바닥이라 인지된 부분의 중심점을 찾는다. 
2) 중심점을 기준으로 PCA 주성분을 찾는다. 
3) 이 값을 바탕으로, 평면방정식 $n^\top x + d = 0$ 의 파라미터를 찾는다. 

```python
def fit_floor_plane_pca(points: np.ndarray, camera_centers: np.ndarray)
    points = np.asarray(points, dtype=np.float64)
    
    # Floor point cloud의 가장 작은 PCA 축은 바닥 평면의 법선이다.
    centroid = points.mean(axis=0)
    centered = points - centroid  #잔차 Residual을 구하고, 
    covariance = centered.T @ centered / len(points)  #공분산을 계산한 다음
    eigenvalues, eigenvectors = np.linalg.eigh(covariance)  #고유값을 구하자. 
    normal = eigenvectors[:, np.argmin(eigenvalues)]  #그러면 법선 벡터를 구할 수 있다. 

    # 법선의 부호 모호성을 없앤다. camera에서 floor 쪽을 향하는 방향을 gravity-down으로 선택한다.
    camera_center = np.median(camera_centers, axis=0)
    if np.dot(normal, centroid - camera_center) < 0:
        normal = -normal
    gravity_down = normal / np.linalg.norm(normal)  #평면 방정식의 파라미터 n에 해당
    plane_offset = -float(np.dot(gravity_down, centroid))  #평면 방정식의 파라미터 d에 해당
    residuals = centered @ gravity_down  # 평면이 잘 놓였는지 알 수 있는 지표

    return {
        'centroid': centroid,
        'covariance': covariance,
        'eigenvalues': eigenvalues,
        'gravity_down': gravity_down,
        'plane_offset': plane_offset,
        'residuals': residuals,
    }

```


### refine coulumns
정렬된 벽줄을 어떻게 분류해내는가에 대한 함수다. 

```python
def refine_aligned_columns(
                              wall_mask: np.ndarray,
                              aligned_depth: np.ndarray,
                              valid_mask: np.ndarray,
                              tau_d: float,
                              segment_depth_gap: float,
                            )                             
    # 출력은 raw semantic wall의 부분집합이다. 새 wall을 만들지 않고 신뢰하기 어려운
    # wall pixel만 제거한다.

    # 변수 초기화
    refined = np.zeros_like(wall_mask, dtype=bool)
    finite_positive = valid_mask & np.isfinite(aligned_depth) & (aligned_depth > 0)

    # Upright view에서는 수직 벽이 column별로 거의 같은 depth를 가져, column 단위 검사가 가능하다.
    for column in range(wall_mask.shape[1]):
        wall_rows = np.flatnonzero(wall_mask[:, column] & finite_positive[:, column])
        if len(wall_rows) == 0:
            continue
        wall_depths = aligned_depth[wall_rows, column]
        # Median은 segmentation 경계의 소수 outlier에 덜 민감한 대표 wall depth다.
        representative_depth = float(np.median(wall_depths))
        non_wall = (~wall_mask[:, column]) & finite_positive[:, column]

        # semantic wall보다 충분히 먼 non-wall 구조가 있으면, 이 column의 wall label은
        # 가려진 배경/잘못된 segmentation일 가능성이 높으므로 전부 버린다 (논문 식 4).
        if np.any(non_wall) and float(np.max(aligned_depth[non_wall, column])) > representative_depth + tau_d:
            continue

        order = np.argsort(wall_depths)
        sorted_rows = wall_rows[order]
        sorted_depths = wall_depths[order]

        # 한 column에 서로 다른 깊이의 벽 후보가 있으면 depth gap으로 분할한 뒤,
        # 가장 먼 segment만 남긴다. 가까운 물체/ghost wall보다 실제 배경 벽을 우선한다 (식 5).
        split_locations = np.flatnonzero(np.diff(sorted_depths) > segment_depth_gap) + 1
        segments = np.split(sorted_rows, split_locations)
        farthest = max(segments, key=lambda rows: float(np.median(aligned_depth[rows, column])))
        refined[farthest, column] = True
    
    
    return refined
```

```python

def refine_wall_masks(
    raw_wall_masks: np.ndarray,
    depth_maps: np.ndarray,
    valid_masks: np.ndarray,
    intrinsics: np.ndarray,
    camera_poses: np.ndarray,
    gravity_down: np.ndarray,
    tau_d: float,
    segment_depth_gap: float,
) -> dict[str, np.ndarray]:
    refined_original = []
    raw_aligned = []
    refined_aligned = []
    depths_aligned = []
    homographies = []
    rotations = []
    image_height, image_width = depth_maps.shape[1:]
    # Frame별 warp → column refinement → 원래 processed raster 복원의 순서다.
    # INTER_NEAREST는 class mask의 boolean 경계를 보존하고, depth만 선형 보간한다.
    for wall, depth, valid, K, pose in zip(raw_wall_masks, depth_maps, valid_masks, intrinsics, camera_poses):

        R = rectification_rotation(pose[:3, :3].astype(np.float64), gravity_down)

        H = K.astype(np.float64) @ R @ np.linalg.inv(K.astype(np.float64))

        depth_hat_source = aligned_depth_from_equation_2(depth, K, R)

        aligned_wall = cv2.warpPerspective(
                            wall.astype(np.uint8), H, (image_width, image_height), flags=cv2.INTER_NEAREST
                            ).astype(bool)
        aligned_valid = cv2.warpPerspective(
                            valid.astype(np.uint8), H, (image_width, image_height), flags=cv2.INTER_NEAREST
                             ).astype(bool)
        aligned_depth = cv2.warpPerspective(
                            depth_hat_source, H, (image_width, image_height), flags=cv2.INTER_LINEAR
                            )
        #여기서 벽정보를 정제한다.        
        aligned_refined = refine_aligned_columns(
                            aligned_wall, aligned_depth, aligned_valid, tau_d, segment_depth_gap
                              )
        original_refined = cv2.warpPerspective(
                                aligned_refined.astype(np.uint8), np.linalg.inv(H),
                                (image_width, image_height), flags=cv2.INTER_NEAREST
                                ).astype(bool)
        
        # Warp 왕복에서 생길 수 있는 경계 pixel을 막기 위해, 원래의 wall mask 및 valid depth와 교집합한다.
        original_refined &= wall & valid

        # 결과값 저장
        refined_original.append(original_refined)
        raw_aligned.append(aligned_wall)
        refined_aligned.append(aligned_refined)
        depths_aligned.append(aligned_depth)
        homographies.append(H)
        rotations.append(R)
    return {
        'refined_wall_masks': np.stack(refined_original),
        'aligned_raw_wall_masks': np.stack(raw_aligned),
        'aligned_refined_wall_masks': np.stack(refined_aligned),
        'aligned_depth_maps': np.stack(depths_aligned).astype(np.float32),
        'H_aligned_px_from_processed_px': np.stack(homographies).astype(np.float32),
        'R_rectified_camera_from_camera': np.stack(rotations).astype(np.float32),
    }
```

```python
def fit_line_least_squares(points: np.ndarray) -> dict[str, np.ndarray | float]:
    points = np.asarray(points, dtype=np.float64)
    if points.ndim != 2 or points.shape[1] != 2 or len(points) < 2:
        raise ValueError(f'line fit은 [N, 2], N>=2가 필요합니다: {points.shape}')
    # 중심을 뺀 covariance의 가장 큰 고유값 방향은 point cloud가 가장 길게 늘어난 접선 방향이다.
    # 그 직교 방향을 unit normal로 삼으면 total least-squares 직선이 된다.
    centroid = points.mean(axis=0)
    centered = points - centroid
    covariance = centered.T @ centered / len(points)
    eigenvalues, eigenvectors = np.linalg.eigh(covariance)
    principal = eigenvectors[:, -1]
    normal = np.array([-principal[1], principal[0]], dtype=np.float64)
    normal /= np.linalg.norm(normal)
    # n/d sign ambiguity를 제거해 serialization과 비교를 deterministic하게 만든다.
    if normal[0] < -1e-12 or (abs(normal[0]) <= 1e-12 and normal[1] < 0):
        normal = -normal
    # normal을 90도 회전해 선을 따라가는 unit direction을 만든다.
    direction = np.array([normal[1], -normal[0]], dtype=np.float64)
    offset = -float(normal @ centroid)
    # support를 direction에 투영한 최솟값/최댓값이 유한 선분의 endpoint와 길이를 정의한다.
    coordinates = centered @ direction
    endpoints = np.stack([
        centroid + float(coordinates.min()) * direction,
        centroid + float(coordinates.max()) * direction,
    ])
    return {
        'normal': normal,
        'offset': offset,
        'direction': direction,
        'endpoints': endpoints,
        'length': float(coordinates.max() - coordinates.min()),
        'centroid': centroid,
        'eigenvalues': eigenvalues,
    }
```

```python

def extract_line_primitives(
                                points_metric: np.ndarray,
                                pixels_uv: np.ndarray,
                                raster_shape: tuple[int, int],
                                resolution_m: float,
                                parameters: dict,
                                random_seed: int,
                            ) -> tuple[list[dict], dict]:
    points = np.asarray(points_metric, dtype=np.float64)
    pixels = np.asarray(pixels_uv, dtype=np.int32)


    # pixel_to_index는 raster 이웃 (u, v)을 metric point의 row index로 되돌리는 lookup table이다.
    pixel_to_index = np.full(raster_shape, -1, dtype=np.int32)
    pixel_to_index[pixels[:, 1], pixels[:, 0]] = np.arange(len(pixels), dtype=np.int32)
    offsets_uv = pixel_neighbor_offsets(
        float(parameters['connectivity_radius_m']), resolution_m
    )
    # KD-tree는 anchor 주변의 초기 PCA 후보만 빠르게 찾는다. 실제 region 확장은 raster 연결성도 만족해야 한다.
    tree = cKDTree(points)
    generator = np.random.default_rng(random_seed)
    unassigned = np.ones(len(points), dtype=bool)
    accepted_labels = np.full(len(points), -1, dtype=np.int32)
    primitives = []
    rejected_region_count = 0
    rejected_point_count = 0
    total_growth_iterations = 0

    # accepted/rejected 여부와 관계없이 방문한 support를 unassigned에서 제거하므로 각 입력 pixel은 한 raw region에만 속한다.
    while np.any(unassigned):
        available = np.flatnonzero(unassigned)
        anchor = int(available[generator.integers(len(available))])
        local = np.asarray(
            tree.query_ball_point(points[anchor], float(parameters['neighborhood_radius_m'])),
            dtype=np.int64,
        )
        local = local[unassigned[local]]
        if len(local) < 3:
            unassigned[anchor] = False
            rejected_region_count += 1
            rejected_point_count += 1
            continue

        # local PCA는 seed 주변의 초기 가설이고, 아래 반복문에서는 늘어난 support 전체로 다시 적합한다.
        initial_model = fit_line_least_squares(points[local])
        local_distance = np.abs(points[local] @ initial_model['normal'] + initial_model['offset'])
        support = np.unique(local[local_distance <= float(parameters['distance_threshold_m'])])
        if anchor not in support:
            support = np.append(support, anchor)
        # 엄격한 distance threshold에서는 anchor만 남을 수 있다.
        # 한 점으로는 직선을 피팅할 수 없으므로 이 점은 rejected로 처리한다.
        if len(support) < 2:
            unassigned[anchor] = False
            rejected_region_count += 1
            rejected_point_count += 1
            continue
        member = np.zeros(len(points), dtype=bool)
        member[support] = True

        # 현재 support의 raster 이웃 중 line 직교거리 조건도 통과한 점만 추가한다.
        # 더 이상 추가될 점이 없으면 fixed point에 도달한 것이다.
        while True:
            support_indices = np.flatnonzero(member)
            model = fit_line_least_squares(points[support_indices])
            neighbor_uv = (
                pixels[support_indices, None, :] + offsets_uv[None, :, :]
            ).reshape(-1, 2)
            inside = (
                (neighbor_uv[:, 0] >= 0)
                & (neighbor_uv[:, 0] < raster_shape[1])
                & (neighbor_uv[:, 1] >= 0)
                & (neighbor_uv[:, 1] < raster_shape[0])
            )
            neighbor_uv = neighbor_uv[inside]
            candidates = pixel_to_index[neighbor_uv[:, 1], neighbor_uv[:, 0]]
            candidates = np.unique(candidates[candidates >= 0])
            candidates = candidates[unassigned[candidates] & ~member[candidates]]
            if len(candidates) == 0:
                break
            candidate_distance = np.abs(
                points[candidates] @ model['normal'] + model['offset']
            )
            added = candidates[candidate_distance <= float(parameters['distance_threshold_m'])]
            if len(added) == 0:
                break
            member[added] = True
            total_growth_iterations += 1

        # 이 region은 이제 재방문하지 않는다. 작은/짧은 region도 여기서 영구 reject된다.
        support_indices = np.flatnonzero(member)
        unassigned[support_indices] = False
        final_model = fit_line_least_squares(points[support_indices])
        if (
            len(support_indices) >= int(parameters['min_support'])
            and final_model['length'] >= float(parameters['min_length_m'])
        ):
            line_index = len(primitives)
            accepted_labels[support_indices] = line_index
            final_model['support_indices'] = support_indices.astype(np.int32)
            final_model['support_count'] = int(len(support_indices))
            primitives.append(final_model)
        else:
            rejected_region_count += 1
            rejected_point_count += int(len(support_indices))

    # 마지막 assert는 모든 입력 point가 정확히 한 번 accepted 또는 rejected 되었음을 확인한다.
    statistics = {
        'input_point_count': int(len(points)),
        'accepted_line_count': int(len(primitives)),
        'accepted_point_count': int(np.count_nonzero(accepted_labels >= 0)),
        'rejected_region_count': int(rejected_region_count),
        'rejected_point_count': int(rejected_point_count),
        'growth_iterations': int(total_growth_iterations),
        'point_labels': accepted_labels,
    }
    assert statistics['accepted_point_count'] + statistics['rejected_point_count'] == len(points)
    return primitives, statistics
```

```python
import numpy as np
import hdbscan
from skimage.measure import CircleModel, ransac


def detect_circles(points, min_cluster_size=20, residual_threshold=0.1):
    labels = hdbscan.HDBSCAN(
        min_cluster_size=min_cluster_size
    ).fit_predict(points)

    circles = []

    for label in np.unique(labels):
        if label == -1:
            continue

        cluster = points[labels == label]

        model, inliers = ransac(
            cluster,
            CircleModel,
            min_samples=3,
            residual_threshold=residual_threshold,
            max_trials=100
        )

        if model is not None:
            cx, cy, r = model.params
            circles.append([cx, cy, r])

    return np.asarray(circles)
```

## 5. 정합과정. Hybrid RANSAC
논문에선 Model Estimation이라고 표현하고 있다. Feature를 비교하는 solver를 정의하고, 그 solver를 이용해 가설(Pose hypothesis)을 설정하고, 이를 RANSAC 방식으로 평가하며 업데이트 해나간다. 최종적으로 scale,rotation,transform 값은 (s,R,t)를 얻는 것이 목적이다. 

 1) BEV와 floorplan에서 각각 line/circle primitive를 준비
 2) 그중 아주 적은 개수의 primitive correspondence를 샘플링
 3) solver를 이용해 similarity transform $(s, R, t)$ 계산, hypothesis 로 저장
 4) 2~3의 과정을 반복하여 RANSAC loop 안에서 반복해서 사용하며 많은 hypothesis 생성정
 5) Model Scoring 단계에서 어떤 hypothesis가 전체 구조와 가장 잘 맞는지 평가, 선택/탈락 진행

이제 이 과정을 설명하기 위해선 Solver를 먼저 설명해야 한다.

- 2L : line 2개 + scale prior를 가지고 매칭하는 것

- LC : line과 circle 1개ㅐ

### 5.2 Hybrid RANSAC 

이제 이 네개의 solver를 가지고 RANSAC 루프에 들어간다. 핵심은 RANSAC 한번에 네개의 solver 모두를 다 돌리는게 아니라 매 iteration마다 3L / 2L / 2C / LC 중 하나를 랜덤하게 선택해서 가설(hypotheesis) 만든다는ㄴ 것이다. 이걸 하이브리드 RANSAC이라고 표현하고 있다. (참조: Camposeco, F., Cohen, A., Pollefeys, M., Sattler, T.: Hybrid camera pose estima-tion. In: CVPR (2018))  Pollefeys 이분... 자주 등장하네. 

Hybrid RANSAC과 관련된 부분은 다음과 같은 순서로 진행된다. 

```
function run_hybrid_ransac(seed):

    RNG(난수생성기) 초기화
    hypotheses = []

    반복(num_iterations):

        solver ← 3L 또는 2L 무작위 선택

        if solver == 3L:
            대응 line 3개 샘플링
            candidates ← 3L solver 실행

        else:
            대응 line 2개 샘플링
            scale ← scale prior에서 샘플링
            candidates ← 2L solver 실행

        for candidate in candidates:
            candidate의 coarse consistency score 계산
            hypotheses에 저장

    return hypotheses
```

Hybrid RANSAC 만 가지고는 문제가 하나 더 있다. correspondece를 찾는 과정에서 전부 나열해 찾는다면, floorplan의 라인 개수가 많아졌을때 경우의 수가 폭증하게 된다.   

이걸 줄이기 위해 논문에선 세가지 pruning 전략을 사용한다. 그리고 이 pruning 전략은 3L 솔버에서만 적용한다. 

1) Line deduplication 
방향과 offset이 매우 비슷한 거의 중복된 line은 제거한다. 이때는 더 긴 segment를 남긴다. BEV와 floorplan양쪽에서 수행한다. 

2) Spartial proximity
BEV는 local 영역만을 나타낸다. 따라서, floorplan에서 3개의 line을 샘플링할때, 서로 공간적으로 가까운 후보들만 선택한다. 이를 위해 line 사이의 거리를 미리 계산해둔다. 이를 통해 line triplet 의 구성시 조합수가 제곱에 비례하는 것을 quasi-linear수준으로 낮출 수 있다. 

3) Normal consistency
하나의 line correspondence로부터 rotation $\mathbf R$을 추정한 뒤, 나머지 두 line까지 포함한 세 line의 normal이 BEV의 대응 line normal과 모두 일관되어야 한다. $\tau_p$는 cosine similarity threshold 인데, 다시말해, 평행하게 잘 일치하는지를 확인하는 과정이다. 이 조건을 만족시키지 못하면 scale과 translation을 계산하기 전에 가설에서 제외한다.

우선, 앞서 수식유도에서 사용되었던 기본 연산식들이다. 좌표변환을 수행하는 Sim(2)와 Line 관련 유틸리티들이다. 

```python
def wrap_angle(angle: float) -> float:
    return float((angle + np.pi) % (2.0 * np.pi) - np.pi)


def rotation_matrix(theta: float) -> np.ndarray:
    cosine, sine = np.cos(theta), np.sin(theta)
    return np.array([[cosine, -sine], [sine, cosine]], dtype=np.float64)


def normal_alignment_angle(source_normal: np.ndarray, target_normal: np.ndarray) -> float:
    # 대응하는 법선의 방향 차이로 후보 회전을 만든다. 직선의 법선은 부호가
    # 뒤집힐 수 있으므로 solver에서는 이 각도와 pi를 더한 각도를 모두 검사한다.
    return wrap_angle(
        np.arctan2(target_normal[1], target_normal[0])
        - np.arctan2(source_normal[1], source_normal[0])
    )


def validate_line_parameters(normals: np.ndarray, offsets: np.ndarray, expected_count: int):
    # 모든 solver가 unit-normal Hesse form n^T x + d = 0을 공유한다.
    # 단위 법선이 아니면 offset의 metric 의미와 scale 식이 달라지므로 초기에 거절한다.
    normals = np.asarray(normals, dtype=np.float64)
    offsets = np.asarray(offsets, dtype=np.float64)
    if normals.shape != (expected_count, 2) or offsets.shape != (expected_count,):
        raise ValueError(
            f'expected normals {(expected_count, 2)}, offsets {(expected_count,)}; '
            f'got {normals.shape}, {offsets.shape}'
        )
    if not np.all(np.isfinite(normals)) or not np.all(np.isfinite(offsets)):
        raise ValueError('line parameters must be finite')
    norms = np.linalg.norm(normals, axis=1)
    if not np.allclose(norms, 1.0, atol=1e-6):
        raise ValueError('line normals must be unit vectors')
    return normals, offsets


def transform_lines(
    normals: np.ndarray,
    offsets: np.ndarray,
    scale: float,
    rotation: np.ndarray,
    translation: np.ndarray,
) -> tuple[np.ndarray, np.ndarray]:
    # x_t = s R x_s + t 를 n^T x + d = 0에 대입하면
    # n_t = R n_s, d_t = s d_s - n_t^T t가 된다. 아래는 synthetic 검증과
    # solver의 선형식을 동일한 좌표/부호 convention으로 연결하는 기준 구현이다.
    target_normals = np.asarray(normals, dtype=np.float64) @ rotation.T
    target_offsets = scale * np.asarray(offsets, dtype=np.float64) - target_normals @ translation
    return target_normals, target_offsets


def transform_points(
    points: np.ndarray, scale: float, rotation: np.ndarray, translation: np.ndarray
) -> np.ndarray:
    return scale * (np.asarray(points, dtype=np.float64) @ rotation.T) + translation


def rotation_error(first: np.ndarray, second: np.ndarray) -> float:
    relative = first @ second.T
    return abs(wrap_angle(np.arctan2(relative[1, 0], relative[0, 0])))
```

3L 변환과 관련된 부분은 다음과 같다. 

```python
def solve_3l(
    source_normals: np.ndarray,
    source_offsets: np.ndarray,
    target_normals: np.ndarray,
    target_offsets: np.ndarray,
    parameters: dict,
) -> list[dict]:
    """세 line correspondence로 scale, rotation, translation을 복원한다.

    회전 후보를 정하면 각 대응선은 s * d_source - n_target^T t = d_target가 된다.
    세 식을 [d_source, n_target_x, n_target_y] [s, -t_x, -t_y]^T = d_target
    로 쌓아 3x3 선형계로 푼다.
    """
    # 입력은 sampler가 만든 순서 있는 correspondence이며, shape/unit-normal을
    # 검증해 잘못된 cache나 caller 오류가 수치 해로 섞이는 것을 막는다.
    source_normals, source_offsets = validate_line_parameters(source_normals, source_offsets, 3)
    target_normals, target_offsets = validate_line_parameters(target_normals, target_offsets, 3)
    # 첫 대응선으로 회전의 기준 각을 정한다. n과 -n이 같은 기하 직선을
    # 표현하므로 180도 ambiguity를 아래 loop에서 명시적으로 전개한다.
    base_theta = normal_alignment_angle(source_normals[0], target_normals[0])
    hypotheses = []

    for theta in (base_theta, wrap_angle(base_theta + np.pi)):
        # 두 법선 방향 가설 각각에 대해 나머지 두 대응선도 같은 회전과
        # 양립하는지 확인한 뒤, 양립할 때만 scale/translation을 계산한다.
        rotation = rotation_matrix(theta)
        rotated_normals = source_normals @ rotation.T
        normal_dots = np.sum(rotated_normals * target_normals, axis=1)
        # |dot|가 1에 가까워야 회전 후 법선이 target 법선 또는 그 반대와
        # 일치한다. 낮으면 correspondence 자체가 이 rotation과 모순된다.
        if np.min(np.abs(normal_dots)) < float(parameters['normal_consistency_cosine']):
            continue

        # line (n, d)와 (-n, -d)는 동일하다. dot의 부호로 target line의
        # 표현을 정렬해 offset 식에서 부호 ambiguity를 없앤다.
        signs = np.where(normal_dots >= 0.0, 1.0, -1.0)
        aligned_target_normals = signs[:, None] * target_normals
        aligned_target_offsets = signs * target_offsets
        # Eq. (9)의 3x3 계수행렬. rank 부족은 평행/중복 line 등으로 인해
        # scale 또는 translation이 유일하게 정해지지 않는 퇴화 최소 샘플이다.
        system = np.column_stack([source_offsets, aligned_target_normals])
        if np.linalg.matrix_rank(system) < 3:
            continue
        # full rank라도 조건수가 너무 크면 작은 offset/normal 오차가 pose를
        # 크게 흔드므로, RANSAC 후보로 사용하지 않고 샘플을 거절한다.
        condition_number = float(np.linalg.cond(system))
        if not np.isfinite(condition_number) or condition_number > float(parameters['max_condition_number']):
            continue

        # solution = [scale, -translation_x, -translation_y].
        # solve를 사용해 역행렬을 명시적으로 만들지 않아 수치 오차를 줄인다.
        solution = np.linalg.solve(system, aligned_target_offsets)
        scale = float(solution[0])
        translation = -solution[1:]
        if not np.isfinite(scale) or scale <= float(parameters['min_scale']):
            continue
        # 음수/0 scale은 좌표계를 반전하거나 붕괴시키므로 물리적으로 유효한
        # Sim(2) 가설이 아니다. residual은 뒤에서 solver 품질을 진단하는 값이다.
        residual = system @ solution - aligned_target_offsets
        hypotheses.append({
            'solver': '3L',
            'scale': scale,
            'rotation': rotation,
            'theta': theta,
            'translation': translation,
            'normal_signs': signs.astype(np.int8),
            'normal_consistency': np.abs(normal_dots),
            'condition_number': condition_number,
            'max_equation_residual': float(np.max(np.abs(residual))),
        })
    return hypotheses
```

2 Line Solver의 구현은 다음과 같다. 

```python
def normals_are_parallel(normals: np.ndarray, angle_threshold_deg: float) -> bool:
    # |cross(n1, n2)| = |sin(angle)|. 2L은 translation의 2개 성분을
    # 두 target normal로 풀기 때문에 두 법선이 평행이면 역행렬이 존재하지 않는다.
    sine = abs(float(
        normals[0, 0] * normals[1, 1] - normals[0, 1] * normals[1, 0]
    ))
    return sine <= np.sin(np.deg2rad(angle_threshold_deg))


def solve_2l(
    source_normals: np.ndarray,
    source_offsets: np.ndarray,
    target_normals: np.ndarray,
    target_offsets: np.ndarray,
    scale: float,
    parameters: dict,
) -> list[dict]:
    """두 line correspondence와 외부 scale 표본으로 Sim(2)를 복원한다.

    Scale은 이 최소 문제에서 관측되지 않으므로 RANSAC이 제공한 prior sample을
    고정한다. 회전/부호를 정렬한 뒤 2x2 식 n_target^T t = s*d_source - d_target를
    풀어 translation을 얻는다.
    """
    source_normals, source_offsets = validate_line_parameters(source_normals, source_offsets, 2)
    target_normals, target_offsets = validate_line_parameters(target_normals, target_offsets, 2)
    # 2L의 scale은 solver 내부에서 재추정하지 않는다. prior 표본이 유효하지
    # 않으면 이후 선형계도 의미가 없으므로 즉시 빈 후보 집합을 돌려준다.
    if not np.isfinite(scale) or scale <= float(parameters['min_scale']):
        return []
    angle_threshold = float(parameters['parallel_angle_threshold_deg'])
    # source 또는 target pair가 평행하면 제약 두 개가 독립적이지 않다.
    # 특히 target pair 평행은 translation 선형계가 singular함을 뜻한다.
    if normals_are_parallel(source_normals, angle_threshold) or normals_are_parallel(target_normals, angle_threshold):
        return []

    base_theta = normal_alignment_angle(source_normals[0], target_normals[0])
    hypotheses = []
    for theta in (base_theta, wrap_angle(base_theta + np.pi)):
        # 3L과 동일하게 line-normal 부호 ambiguity에 대한 두 회전 가지를
        # 모두 검사한다. 이 단계는 scale prior와 독립적인 기하 검증이다.
        rotation = rotation_matrix(theta)
        rotated_normals = source_normals @ rotation.T
        normal_dots = np.sum(rotated_normals * target_normals, axis=1)
        if np.min(np.abs(normal_dots)) < float(parameters['normal_consistency_cosine']):
            continue
        signs = np.where(normal_dots >= 0.0, 1.0, -1.0)
        aligned_target_normals = signs[:, None] * target_normals
        aligned_target_offsets = signs * target_offsets
        # 2x2 target-normal 행렬의 conditioning을 확인한다. 거의 평행한 선은
        # 앞의 angle threshold를 통과할 수도 있으므로 추가 안전장치가 필요하다.
        condition_number = float(np.linalg.cond(aligned_target_normals))
        if not np.isfinite(condition_number) or condition_number > float(parameters['max_condition_number']):
            continue
        # 고정된 scale에서 남은 미지수는 translation뿐이다. 이 식은 line
        # transform d_t = s*d_s - n_t^T*t를 translation에 대해 정리한 것이다.
        right_hand_side = scale * source_offsets - aligned_target_offsets
        translation = np.linalg.solve(aligned_target_normals, right_hand_side)
        # exact minimal solver에서는 residual이 수치 정밀도 수준이어야 한다.
        # 값은 버리지 않고 hypothesis에 담아 synthetic/RANSAC 진단에 사용한다.
        residual = aligned_target_normals @ translation - right_hand_side
        hypotheses.append({
            'solver': '2L',
            'scale': float(scale),
            'rotation': rotation,
            'theta': theta,
            'translation': translation,
            'normal_signs': signs.astype(np.int8),
            'normal_consistency': np.abs(normal_dots),
            'condition_number': condition_number,
            'max_equation_residual': float(np.max(np.abs(residual))),
        })
    return hypotheses
```

```python
def run_hybrid_ransac(random_seed: int) -> tuple[list[dict], dict]:
    """한 seed에서 3L/2L 최소 샘플 가설을 생성하고 coarse 점수만 계산한다.

    RANSAC의 한 iteration은 '최소 대응 집합 하나 -> 가능한 모든 해(candidate)'이다.
    따라서 하나의 최소 solver가 복수의 Sim(2) 해를 반환하면, 모두 보존한 뒤
    다음 단계의 coarse-to-fine ranking에서 기하 일관성으로 구분한다.
    """
    # Seed별 RNG를 분리해 실행 결과를 재현하고, seed 간 독립적인 표본을 만든다.
    generator = np.random.default_rng(random_seed)
    enabled = list(ransac_cfg['enabled_solvers'])
    hypotheses = []
    selected_counts = {name: 0 for name in enabled}
    empty_solver_outputs = 0
    start = time.perf_counter()

    # --- RANSAC sampling loop -------------------------------------------------
    # 매 반복은 무작위 최소 샘플로 하나 이상의 pose 가설을 제안한다. 아직
    # 최적 가설을 고르지 않으며, 이 cell은 후보 생성과 저비용 coarse scoring만 한다.
    for iteration in range(int(ransac_cfg['num_iterations'])):
        # Hybrid RANSAC: 3L(스케일을 함께 풂) 또는 2L(스케일 prior 필요)를
        # 균등 확률로 선택한다. 선택 횟수는 solver 편향을 확인하기 위해 기록한다.
        solver_type = enabled[int(generator.integers(len(enabled)))]
        selected_counts[solver_type] += 1
        if solver_type == '3L':
            # 사전 구축한 유효 3-line 대응 pool에서 한 triplet을 균등 샘플링한다.
            # 3L은 Sim(2)의 scale까지 기하적으로 결정하므로 별도 scale 표본이 없다.
            source_indices, target_indices = correspondence_pool_3l[
                int(generator.integers(len(correspondence_pool_3l)))
            ]
            candidates = solve_3l_indices(source_indices, target_indices)
            sampled_scale = np.nan
        elif solver_type == '2L':
            # 2L 최소 문제는 scale이 부족하므로, 대응 pair와 scale prior를 함께 뽑는다.
            source_indices, target_indices = correspondence_pool_2l[
                int(generator.integers(len(correspondence_pool_2l)))
            ]
            # GGD prior에서 scale을 표본화한다. prior_mean을 중심으로 한 이 값은
            # solver 입력일 뿐이며, 뒤의 dense consistency score가 가설을 평가한다.
            sampled_scale = prior_mean + float(
                gennorm.rvs(
                    prior_beta, scale=prior_scale_parameter, random_state=generator
                )
            )
            candidates = solve_2l_indices(source_indices, target_indices, sampled_scale)
        else:
            raise ValueError(f'unsupported Gibson solver: {solver_type}')
        # 퇴화된 샘플 또는 수치적으로 불가능한 경우 solver가 빈 결과를 반환할 수 있다.
        # 이 표본은 inlier/outlier 판정을 시도하지 않고 다음 무작위 표본으로 넘어간다.
        if not candidates:
            empty_solver_outputs += 1
            continue
        # 최소 solver는 대칭성 때문에 여러 해를 낼 수 있다. 하나도 임의로 버리지 않고
        # 각 해를 별도의 RANSAC 가설로 채점해 후속 ranking에 전달한다.
        for candidate_id, hypothesis in enumerate(candidates):
            hypothesis.update({
                'random_seed': int(random_seed),
                'iteration': int(iteration),
                'candidate_id': int(candidate_id),
                'source_indices': tuple(int(x) for x in source_indices),
                'target_indices': tuple(int(x) for x in target_indices),
                'sampled_scale': float(sampled_scale),
            })
            # Provenance는 결과 재현/디버깅용이다: 어떤 seed, 반복, 최소 샘플과
            # 2L scale 표본에서 이 가설이 나왔는지 저장한다.
            hypothesis['coarse_consistency'] = consistency_score(
                bev_coarse_points, hypothesis, tau_c_m
            )
            # 전체 wall-point가 후보 Sim(2)에 얼마나 일관되는지 coarse threshold
            # tau_c_m로 평가한다. 이 점수로 후보를 shortlist한 뒤 fine score를 계산한다.
            hypotheses.append(hypothesis)

    # Sampling 자체의 품질/비용을 보고할 통계. 빈 solver 결과는 후보 수와
    # iteration 수가 다른 이유를 설명하므로 명시적으로 남긴다.
    statistics = {
        'seed': int(random_seed),
        'iterations': int(ransac_cfg['num_iterations']),
        'solver_selection_counts': selected_counts,
        'empty_solver_outputs': int(empty_solver_outputs),
        'generated_hypotheses': int(len(hypotheses)),
        'runtime_seconds': float(time.perf_counter() - start),
    }
    return hypotheses, statistics


all_hypotheses = []
seed_statistics = []
# 여러 seed를 실행해 특정 난수열에 대한 의존도를 낮춘다. 각 seed의 모든 후보를
# 합친 뒤, 다음 cell에서 seed별 coarse top-k를 먼저 선택한다.
for random_seed in part6_cfg['random_seeds']:
    seed_hypotheses, statistics = run_hybrid_ransac(int(random_seed))
    all_hypotheses.extend(seed_hypotheses)
    seed_statistics.append(statistics)
    print(statistics)
assert all_hypotheses
print('total hypotheses:', len(all_hypotheses))

```
```
for each RANSAC iteration:

    1. solver를 하나 선택
       solver ∈ {3L, 2L, 2C, LC}

    2. 선택된 solver에 맞는 minimal sample 추출

    3. minimal sample로 similarity transform hypothesis 계산
       H = (s, R, t)

    4. hypothesis 평가
       Cc = consistency_score(H)
       Cv = violation_score(H)

    5. 최종 score 계산
       C = Cc - Cv

    6. 현재 best score보다 높으면
       best_H = H
       best_score = C

return best_H
```

코드의 구현은 다음과 같다. 이 계산을 RANSAC 중 계속 수행한다. 

```python
def transform_points(points: np.ndarray, hypothesis: dict) -> np.ndarray:
    # hypothesis는 BEV metric 좌표를 floorplan metric 좌표로 보내는 Sim(2)이다:
    # p_floor = scale * R * p_bev + translation. consistency score는 이 방향을 쓴다.
    return hypothesis['scale'] * (points @ hypothesis['rotation'].T) + hypothesis['translation']


def inverse_transform_points(points: np.ndarray, hypothesis: dict) -> np.ndarray:
    # 위 Sim(2)의 역변환이다. violation score에서는 floorplan의 벽을 관측 BEV
    # free-space와 비교해야 하므로 floorplan -> BEV 방향이 필요하다.
    return ((points - hypothesis['translation']) @ hypothesis['rotation']) / hypothesis['scale']


def consistency_score(points: np.ndarray, hypothesis: dict, threshold_m: float) -> float:
    """변환된 점 중 floorplan 벽 threshold 이내에 있는 비율(C^c)을 반환한다.

    distance field를 사용하므로 모든 점-벽 segment 거리를 다시 계산하지 않는다.
    결과는 [0, 1] 범위이며, 1은 모든 입력 점이 floorplan wall과 일관됨을 뜻한다.
    """
    # BEV wall point를 후보 pose로 floorplan metric 좌표에 정렬한다.
    transformed = transform_points(points, hypothesis)
    distances, _, _ = sample_distance_field(
        transformed, floorplan_wall_distance_m, T_floor_px_from_metric
    )
    # 각 변환 점에서 가장 가까운 floorplan wall까지의 거리를 조회하고,
    # 허용 오차 이내인 점의 비율을 inlier-like consistency로 사용한다.
    return float(np.mean(distances < threshold_m))


def violation_score(hypothesis: dict, threshold_m: float) -> tuple[float, int]:
    """관측 free-space 안에 놓인 floorplan 벽의 비율(C^v)과 표본 수를 반환한다.

    좋은 pose라면 floorplan의 벽은 BEV에서 벽/미관측 영역에 놓여야 한다. 따라서
    명확히 비어 있다고 관측된 곳에 위치하고 clearance가 큰 벽은 위반으로 센다.
    """
    # 가설을 역적용해 floorplan wall sample을 BEV metric 좌표로 되돌린다.
    inverse_floor_walls = inverse_transform_points(floorplan_wall_points, hypothesis)
    # BEV free-space mask를 인덱싱할 수 있도록 metric 좌표를 pixel (u, v)로 바꾼다.
    uv = metric_to_uv(inverse_floor_walls, T_bev_px_from_metric)
    rounded = np.rint(uv).astype(np.int64)
    # 이미지 밖의 sample은 관측 여부를 판정할 수 없으므로 free-space 위반에서 제외한다.
    inside = (
        (rounded[:, 0] >= 0) & (rounded[:, 0] < bev_free_space.shape[1])
        & (rounded[:, 1] >= 0) & (rounded[:, 1] < bev_free_space.shape[0])
    )
    # inside AND bev_free_space인 sample만 '벽이 비어 있는 관측 공간에 들어감'을
    # 검증할 근거가 있다. 나머지는 unknown으로 취급해 패널티를 주지 않는다.
    in_observed_free = np.zeros(len(inverse_floor_walls), dtype=bool)
    in_observed_free[inside] = bev_free_space[rounded[inside, 1], rounded[inside, 0]]
    count = int(in_observed_free.sum())
    if count == 0:
        # 비교 가능한 free-space 교집합이 없을 때의 score는 논문에 명시되지 않아
        # config의 보수적 기본값(현재 0.0)으로 처리하고 표본 수도 함께 반환한다.
        return float(scoring_cfg['empty_free_intersection_violation']), 0
    # free-space 내부에서도 실제 BEV 벽에서 멀리 떨어질수록 위반이 더 확실하다.
    # clearance distance field에서 그 거리를 읽어 threshold 초과 비율을 계산한다.
    clearance, _, _ = sample_distance_field(
        inverse_floor_walls[in_observed_free],
        bev_clearance_distance_m,
        T_bev_px_from_metric,
    )
    return float(np.mean(clearance > threshold_m)), count


# 설정은 pixel 단위이므로 각 grid의 m/pixel 해상도를 곱해 두 score의 metric
# threshold로 변환한다. floorplan consistency와 BEV violation은 서로 다른 grid를 쓴다.
tau_c_m = float(scoring_cfg['tau_c_px']) * floorplan_resolution
tau_v_m = float(scoring_cfg['tau_v_px']) * bev_resolution
print('tau_c/tau_v [m]:', tau_c_m, tau_v_m)
```

## 결론. 

우선, 2D 캐드도면과, RGB만을 이용해 만든 3D 공간을 어떻게 매칭하는가에 대해 매우 좋은 아이디어를 제시한건 높이 평가 한다. 정말 아이디어가 좋았다. 선과 원을 추출하는 방법들과, 그것을 비교하는 방법에 있어서 수학적인 해법들은 정말 참신했다.  

다만, 이 방법이 SOTA로 보기에는 어려운점은 아쉽다. 우선 퍼포먼스가 충분히 나오진 않는다는 것과, 다른 환경과 다른 도면에서 어떻게 수행될지 확실하지 않다는 것이 걱정된다. 

특히 데이터셋들의 도면들이 매우 깔끔하게 정제되어있는데, 이런 도면을 얻지 못한다면 특징점 비교에 어려움이 있지 않을까 우려된다. 아마 필드 적용에선 이 단계부터 벽에 부딛히지 않을까 생각된다. 

3D depth 추정까지 DL 모델에 의존하다보니 연산속도에 제약이 크고, 임베디드화에 걱정점이 있다. 마찬가지로 사물인식 역시 DL 모델을 사용하기에, GPU의 핸들링이나, 메모리 관리에서 주의를 요한다. 아.. 그러네.. 메모리 체크 못해봤다.. 이런 부분들은 RGBD센서를 이용한 3D reconstruction 알고리즘들을 사용하면 충분히 대체가능하지 않을까 하는 생각도 해본다. 

벽을 추출하는 과정에서도 잘못된 벽을 날리는 방법이라던가, 문/통로의 처리 방식 자체는 참신한데, 실제로 했을 경우 유리창이 있을때 벽이 통째로 없어지는걸 봤다. 분명 잘못이긴 한데, 하긴.. 다른 2D도면에선 창문 기호가 있고, 이걸 벽으로 치환하는게 잘 안되기도 했다. 그걸 생각하면 차라리 창문을 지워버리고 뚫린 공간처럼 인식하는것도 의미는 있겠네...

덤으로, 논문 자체에 대한 것보다 논문에서 언급하는 여러 CV 관련 이론들이나 기하학 이론들, 그리고 Related work에서 소개된 논문들이 매우 도움이 되는 논문이다. 덕분에 논문 외적으로 많은 공부가 되었다.
